# Nepalese Food Nutrition Tracker

## About the Project

The Nepalese Food Nutrition Tracker is a web-based application designed to help users track their daily food consumption and nutritional intake, with a focus on Nepalese foods.

This project is being developed as a fourth-semester academic project.

## Objectives

- Track daily calorie intake.
- Record protein, carbohydrates, and fats.
- Maintain a database of Nepalese foods.
- Record meals and serving quantities.
- View daily, weekly, and monthly nutrition reports.
- Set and monitor personal nutrition goals.

## Technologies Used

- HTML
- CSS
- PHP
- MySQL
- XAMPP
- Git and GitHub

## Planned Features

- Food management using CRUD operations.
- Daily food diary.
- Automatic nutrition calculations.
- Nutrition goals.
- Daily, weekly, and monthly reports.
- Green-and-cream user interface.

## Local Setup

1. Install XAMPP.
2. Place the project folder inside `C:\xampp\htdocs\`.
3. Start Apache and MySQL.
4. Create the project database using phpMyAdmin.
5. Configure the local database connection.
6. Open `http://localhost/nepali_food_tracker/` in your browser.
